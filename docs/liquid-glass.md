# 液态玻璃试验（本地 v0.1.9）

在用量条右侧 `...` 菜单的“背景”中选择“液态玻璃（实验）”。同一菜单可切回“实色”或“透明”；设置会保存。升级已有配置时默认保持原有背景，本机本次试用单独开启了玻璃。

## 已实现

- 原生逐像素透明的圆角玻璃胶囊，透出实时背景。
- 细镜面边缘、内侧明暗过渡和轻微下方阴影，近似玻璃边缘的厚度感。
- 根据标题栏环境色调整轻微染色，跟随浅色／深色外观。
- 高光随鼠标在玻璃上的位置变化；文字、进度条与设置按钮保持清晰。
- 使用灰度抗锯齿与独立覆盖率蒙版，避免把文字一起变透明或出现色键边缘。
- 静止时复用上一帧；没有新增连续动画定时器、框架、截图缓存或后台服务。
- 原有颜色、额度读取、拖动、双击、最大化、全屏与自启动逻辑保留。

## 效果边界

这是一种 Liquid Glass 风格的轻量光学近似，并非苹果的原生材质，也没有实现对背后内容的真实折射、扭曲或视角追踪。背景由 Windows 实时透明合成透出；边缘镜面、透镜感由材质模型绘制。当前只读取标题栏附近的七个颜色像素，不截取、保存或上传背景图片。

均匀标题栏上的效果会比较克制；换成有颜色变化的背景时，更容易看出透明与边缘反光。设置弹出菜单沿用 Windows 原生菜单，尚未改成玻璃菜单。

## 实现与验证

使用 [UpdateLayeredWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow) 和预乘 BGRA，GDI 分别绘制颜色、灰度覆盖率，再叠加到玻璃材质。切换逐像素透明与实色模式时重置 `WS_EX_LAYERED`。合成或分配失败时回退为可用的实色背景。

32 项自动化测试通过，覆盖材质透明度与预乘颜色、鼠标／环境响应、前景不透明度、尺寸保护、绘图资源释放、玻璃与传统绘制模式切换、透明文字平滑合成，以及原有窗口生命周期与设置。实际桌面已确认用量条及菜单显示、菜单收起正常。另一个对话中的字体与闪动修复已保留，详见[绘制说明](rendering.md)。

玻璃初版在本机正常显示、菜单关闭时约 31 秒采样：主进程驻留内存约 13.0 MiB，平均 CPU 约占一个逻辑核心的 0.05%，句柄数稳定。保留字体与重绘修复后的复测为主进程 11.28–11.29 MiB，专用提交约 1.9 MiB，CPU 增量低于计时分辨率；包含官方额度读取进程和控制台宿主约 74–78 MiB。此为短时静止观察，不是鼠标持续交互、所有设备或长期运行的保证。

此版本仅作本机试用，未发布 GitHub Release；已发布的 v0.1.8 保持不变。真实背景折射需要单独评估实现成本与持续资源消耗。

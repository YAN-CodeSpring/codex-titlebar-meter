# 字体与闪动修复（本地开发版）

此修改基于工作区现有 v0.1.9 玻璃效果开发代码，保留已有设置，不修改已发布的 v0.1.8 文件。

- 中文默认使用 Microsoft YaHei UI（微软雅黑 UI），13 个逻辑像素；英文使用 Segoe UI，12 个逻辑像素。字体尺寸跟随显示器 DPI。
- 使用灰度抗锯齿。透明背景改用逐像素 alpha 合成，避免为了色键透明而关闭字体抗锯齿。
- 进一步修正小字号笔画粗细不均：先按 3 倍分辨率绘制内容，再用面积平均法缩回实际像素尺寸。彩色文字与覆盖蒙版使用相同采样，保留透明边缘；只在需要新帧时处理。参见[微软对 GDI 小字号抗锯齿限制的说明](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createfontw)。
- 实色背景先在离屏缓冲中绘制完整内容，再一次复制到窗口，减少清背景和画字之间的空白帧。
- 每 250 毫秒仍检查窗口跟随，但仅在位置、尺寸、所有者或可见性变化时重新设置窗口位置。实色模式仅在显示内容、配色、语言、尺寸、DPI 或数据过期状态变化时请求重绘。
- 透明度模式仅在切换时重设；玻璃和透明模式复用帧内容比较，静止时不重新提交相同图像。
- 窄窗口采样主题颜色时排除用量条自身，避免把已合成的玻璃或透明内容反复作为背景输入。
- 透明背景继续保留可点击的设置按钮；内存或合成分配失败时回退到实色显示。
- 设置菜单增加“形状 → 圆角 / 方角”，默认圆角，选择持久保存。双额度使用等宽独立面板，中间留 6 个逻辑像素的透明间隔；两个面板统一使用所选形状，单额度则只保留一块面板。文字、进度条和按钮共同裁切，不会填平圆角或连接中间间隙。

35 项自动化测试通过，包含缩采样的颜色保持与分数笔画覆盖，以及透明文字的实际 GDI 绘制与 alpha 合成检查，覆盖背景透明、文字平滑边缘、设置按钮不透明及预乘颜色有效性。另覆盖 100%、125%、150%、200% 缩放下两个面板的圆角／方角一致性、前景不会跨越透明间隙，以及单面板没有多余间隙。已在本机查看玻璃模式中文显示与双圆角面板效果；静态截图不能证明所有场景下完全没有闪动，仍以实际连续使用效果为准。

本机另采样约 31 秒：主程序驻留内存 11.28–11.29 MiB，专用提交内存约 1.9 MiB，采样期间 CPU 增量低于计时分辨率，句柄未增长。额度读取进程约 52–56 MiB，控制台宿主约 11 MiB，仅有一个额度读取进程，无本工具缓存 CLI 孤立进程。这是短时观察，不代表长期上限。
